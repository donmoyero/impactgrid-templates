# 🦷 APEX DENTAL — Dental Practice Template

A premium, framework-free HTML template for dental practices and clinics. The design features a navy + ocean blue palette with a coral accent, clean medical typography, and a trustworthy, professional atmosphere that communicates care and expertise.

## 📸 Screenshot

![Homepage Preview](screenshot.png)

## 🎨 Design System

| Token | Value | Usage |
|-------|-------|-------|
| `--navy` | `#1B3A5C` | Headings, dark sections, primary |
| `--ocean` | `#2C7B9E` | Accents, links, focus states |
| `--sky` | `#E8F4F8` | Soft section backgrounds |
| `--coral` | `#E86F5E` | CTAs, emergency accent |
| `--ink` | `#1A1F36` | Body text |
| `--muted` | `#5A6B7D` | Secondary text |
| Headings | DM Serif Display | Trustworthy modern serif |
| Body | Inter | Clean medical sans |

## 📄 Pages

| Page | Description | Sections |
|------|-------------|----------|
| [index.html](index.html) | Home — full-width hero with crossfading clinic photos | Services grid (4), About split, Stats bar, Team (5), Testimonials (3), CTA |
| [about.html](about.html) | Our story | Story split, Stats, Values cards |
| [services.html](services.html) | Full treatment list | 8 service cards, Treatment timeline (4 steps) |
| [team.html](team.html) | Meet the team | 5 dentist cards, Insurance & payment plans |
| [contact.html](contact.html) | Appointment booking | Form (name, email, phone, reason, date, notes), Contact card with hours & emergency line |

## ⚙️ Tech Stack

- **HTML5** — semantic markup, accessibility-first
- **CSS3** — custom properties, Grid, Flexbox, `clamp()`, `aspect-ratio`
- **Vanilla JS** — IntersectionObserver, hero crossfade, mobile nav, form validation
- **Fonts** — Google Fonts (DM Serif Display + Inter)
