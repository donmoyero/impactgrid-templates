# 🎙️ Vox Digital — Full-Service Marketing Agency HTML Template

A premium, framework-free HTML template for a digital marketing & creative agency. Vox Digital features a striking animated gradient hero, typing headline, services, portfolio, testimonials, team and blog — all built with clean HTML5, CSS3 and vanilla JavaScript.

## 🎨 Design System

| Token | Value | Usage |
|---|---|---|
| `--midnight` | `#0F0E2E` | Backgrounds, footer, headings |
| `--pink` | `#FF3D6A` | Primary accent, CTAs, highlights |
| `--cyan` | `#00D4FF` | Secondary accent, tags |
| `--lavender` | `#7C6CF0` | Tertiary accent, icons |
| `--bg` | `#F4F6FC` | Page background |
| `--white` | `#FFFFFF` | Cards, sections |
| `--gray` | `#6B7280` | Body text |
| Syne (600/700/800) | — | Headings |
| Space Grotesk (300/400/500) | — | Body text |

## 📄 Pages

| Page | File | Highlights |
|---|---|---|
| [Home](index.html) | `index.html` | Hero, services, about, portfolio, clients, testimonials, team, blog, contact |
| [About](about.html) | `about.html` | Story, stats, why-us, team |
| [Services](services.html) | `services.html` | Service cards + detailed service sections |
| [Portfolio](portfolio.html) | `portfolio.html` | Project gallery grid |
| [Blog](blog.html) | `blog.html` | Article cards + newsletter CTA |
| [Contact](contact.html) | `contact.html` | Form, contact info, working hours |
| [404](404.html) | `404.html` | Error page |

## 🛠 Tech Stack

- **HTML5** — semantic markup, accessible
- **CSS3** — custom properties, Grid, Flexbox, `clamp()`, animations
- **Vanilla JavaScript** — reveal on scroll, mobile nav, form validation, back-to-top
- **Google Fonts** — Syne + Space Grotesk
- No frameworks, no build step, no dependencies

## 🖼 Images

All imagery lives in `assets/img/` — hero background, service visuals, portfolio shots, team portraits, testimonials and client marks. Optimized and ready for production.
