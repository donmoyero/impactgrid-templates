# 🔥 IRONARC — Welding Services Template

A premium, framework-free HTML template for welding and metal fabrication businesses. The design features a charcoal + safety orange industrial palette with a weld-spark yellow accent, bold uppercase Oswald headings, and a workshop-grade atmosphere that communicates strength, precision, and craftsmanship.

## 🎨 Design System

| Token | Value | Usage |
|-------|-------|-------|
| `--char` | `#1C1E21` | Header, stats bar, dark sections, CTA banners |
| `--steel` | `#3A4048` | Labels, secondary text on light surfaces |
| `--orange` | `#F26522` | Primary CTAs, accents, prices, active states |
| `--spark` | `#FFB100` | Testimonial stars, highlight accents |
| `--bg` | `#F4F4F1` | Page background |
| `--card` | `#FFFFFF` | Cards, form inputs, contact card |
| `--ink` | `#17181B` | Footer background, body text |
| `--muted` | `#5F646B` | Secondary body copy |
| `--line` | `#DFE1DE` | Card and input borders |
| Headings | Oswald | Condensed industrial, uppercase |
| Body | Source Sans 3 | Clean readable sans |

## 📄 Pages

| Page | Description | Sections |
|------|-------------|----------|
| [index.html](index.html) | Home — full-width crossfading hero with charcoal overlay | Stats bar (4), Services grid (8), About split with checklist, Process (4 numbered steps), Team (4), Testimonials (4), CTA banner |
| [about.html](about.html) | Our story | Story split with framed image, Certifications & values (3), Team (4), CTA |
| [services.html](services.html) | Services & pricing | 8 detailed service cards with price ranges and process lists, Materials & processes (3), CTA |
| [contact.html](contact.html) | Quote request & contact | Form (name, email, phone, service select, project details, notes), Contact info card with hours & emergency service, CTA |
| [404.html](404.html) | Page not found | Giant 404 Oswald headline, back-to-home link |

## ⚙️ Tech Stack

- **HTML5** — semantic markup, accessibility-first
- **CSS3** — custom properties, Grid, Flexbox, `clamp()`, `aspect-ratio`
- **Vanilla JS** — IntersectionObserver, hero crossfade, mobile nav, form validation
- **Fonts** — Google Fonts (Oswald + Source Sans 3)
