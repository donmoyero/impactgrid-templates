# 🥐 CRUMB &amp; CO. — Cafe &amp; Bakery Template

A premium, framework-free HTML template for artisan bakeries and cafes. The design features a warm caramel + cream palette, elegant serif headings, and an inviting, handcrafted atmosphere that communicates quality and care.

## 📸 Screenshot

![Homepage Preview](screenshot.png)

## 🎨 Design System

| Token | Value | Usage |
|-------|-------|-------|
| `--caramel` | `#B77D3E` | CTA, accents, prices |
| `--caramel-dark` | `#996A33` | Hover states |
| `--espresso` | `#362A20` | Body text, dark sections |
| `--cream` | `#FBF5EE` | Page background, soft sections |
| `--peach` | `#F5D6C6` | Soft accents, icon backgrounds |
| `--muted` | `#7A6A5E` | Secondary text |
| Headings | Playfair Display | Elegant serif, italic accent |
| Body | Nunito Sans | Friendly rounded sans |

## 📄 Pages

| Page | Description | Sections |
|------|-------------|----------|
| [index.html](index.html) | Home — artisan bakery hero | Featured cakes (3), Offer banner, Menu preview (4), Stats bar, Team (3), Testimonials (3), CTA |
| [about.html](about.html) | Our story | Story split, Stats, Values cards, Team |
| [menu.html](menu.html) | Full menu | Cakes grid (3), Pastries & bread (8), Drinks (4 on dark) |
| [services.html](services.html) | Services & catering | Custom cakes, 4 service packages, Stats |
| [contact.html](contact.html) | Order & contact | Order form (name, email, phone, order type, date, details), Contact card with hours |

## ⚙️ Tech Stack

- **HTML5** — semantic markup, accessibility-first
- **CSS3** — custom properties, Grid, Flexbox, `clamp()`, `aspect-ratio`
- **Vanilla JS** — IntersectionObserver, mobile nav, form validation
- **Fonts** — Google Fonts (Playfair Display + Nunito Sans)
